# 🌹 عالم العطور — نظام إدارة طلبات متجر العطور

متجر عطور عربي متكامل مع لوحة تحكم للمدير، مبني بـ Node.js + Express + SQLite.

## 🚀 تشغيل المشروع

```bash
# تثبيت المتطلبات
npm install

# تشغيل الخادم
npm start

# أو للتطوير مع إعادة التشغيل التلقائي
npm run dev
```

ثم افتح المتصفح على:
- **المتجر:** http://localhost:3000
- **لوحة التحكم:** http://localhost:3000/admin.html

## 🔌 API Endpoints

| الطريقة | المسار                    | الوصف                        |
|--------|--------------------------|------------------------------|
| GET    | /api/products             | المنتجات المتاحة (للعملاء)    |
| GET    | /api/products/all         | كل المنتجات (للمدير)          |
| POST   | /api/products             | إضافة منتج                   |
| PUT    | /api/products/:id         | تعديل منتج                   |
| DELETE | /api/products/:id         | حذف منتج                     |
| GET    | /api/orders               | كل الطلبات (للمدير)           |
| GET    | /api/orders/:id           | تفاصيل طلب واحد              |
| POST   | /api/orders               | تسجيل طلب جديد               |
| PUT    | /api/orders/:id/status    | تحديث حالة طلب               |
| GET    | /api/stats                | إحصائيات لوحة التحكم          |

## ✨ المميزات

### المتجر (للعملاء)
- عرض المنتجات بشبكة أنيقة بثيم ذهبي داكن
- سلة تسوق جانبية (Sidebar)
- محدد الكمية لكل منتج
- نموذج طلب كامل (الاسم، الهاتف، المدينة، العنوان)
- رسالة نجاح مع رابط واتساب جاهز بتفاصيل الطلب
- استجابة كاملة على الجوال

### لوحة التحكم (للمدير)
- إحصائيات فورية (الطلبات، الإيرادات، المخزون)
- إدارة المنتجات (إضافة/تعديل/حذف)
- إدارة الطلبات مع تصفية حسب الحالة
- تغيير حالة الطلب (معلق / مؤكد / تم التوصيل / ملغي)
