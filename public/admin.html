# العميل الهاتف المدينة الإجمالي الحالة التاريخ عرض

⚙️ إعدادات البريد الإلكتروني (Gmail / SMTP)

لإرسال رسائل التفعيل وأكواد التحقق إلى إيميلات العملاء الحقيقية مباشرة دون أي وسيط، اضبط بيانات الإرسال هنا:

🚀 لماذا Brevo API هو الحل الأفضل لموقعك على Render؟
منصة Render تحظر بورتات SMTP التقليدية (465 و 587) في الخطة المجانية، بينما Brevo API يرسل الرسائل عبر منفذ HTTPS الآمن والمفتوح دائماً ويمنحك 300 رسالة مجانية يومياً!
خطوات التفعيل المجاني (دقيقة واحدة):
1. سجل مجاناً عبر حساب Google في موقع: www.brevo.com
2. من القائمة العلوية اضغط على اسمك ثم اختر SMTP & API.
3. اضغط على Generate a new API key وانسخ المفتاح (يبدأ بـ xkeysib-...).
4. ضع المفتاح في خانة كلمة المرور أدناه، وضع إيميلك المسجل به في خانة البريد ثم اضغط حفظ.
⚠️ تنبيه Gmail مع Render: منصة Render في الخطة المجانية تحظر بورت 465 مما يسبب انتهاء الوقت (Timeout). إذا كنت ترغب باستخدام Gmail يجب ترقية خدمة Render إلى خطة مدفوعة، أو استخدام خيار Brevo API المجاني أعلاه.
